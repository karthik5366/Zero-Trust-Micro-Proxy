# ZetaShield Telemetry Dashboard (Phase 2 Roadmap)

This directory is designated for the Phase 2 real-time security observability and administrative console.

## Architecture & Objectives
- **Real-Time Security Graph:** Visual representation of service-to-service topology and blocked lateral movement attempts.
- **Audit Log Ingestion:** Visual aggregation of `audit.log.jsonl` streams (ALLOW, DENY, ERROR events).
- **Policy Management UI:** Interactive editor for modifying and deploying `policy.yaml` rules live to the gateway.
